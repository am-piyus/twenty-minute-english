# Twenty Minute English

A daily 20-minute spoken-English session for two: welcome, pick your name, spin a topic wheel, read 3 minutes, record 2 minutes of speaking, retry yesterday's mistakes, learn one rule, answer questions on the wheel's topic with instant feedback. Back and Skip on every step.

One static page (`index.html`) on GitHub Pages. Recordings and results upload to a private Supabase Storage bucket (insert only, with the project's publishable key); a laptop step moves them to Drive.
